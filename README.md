# Paws & Potjie

**A comfort kitchen for dogs and their humans.**

Paws & Potjie is a South African comfort-food experience built for the DEV Frontend Challenge: Comfort Food Edition, with a dog-first interaction layer inspired by the Dog Days prompt.

This repository is being evolved under KPGS governance into a TypeScript 7 MERN Adaptive PWA. The public experience is designed to remain useful on mobile, slow networks, reduced-motion devices, and offline after first load.

## Status

- Source of truth: this repository
- Runtime: React 19 + Vite 8 + TypeScript 7
- PWA: adaptive service worker + install manifest
- API: Express + optional MongoDB persistence
- Governance: local KPGS scene contracts and receipts

> Fictional restaurant concept. Dog menu content is illustrative and not veterinary advice.
